# 文字世界（game-textworld）

TypeScript + Canvas 2D 的动态文字世界。核心引擎与 React、Canvas 和 DOM 解耦，通过 `ITextMeasure` 注入文字尺寸。

在仓库根目录运行（Node.js >= 20.19，pnpm >= 9）：

```sh
pnpm install
pnpm --filter game-textworld dev
```

打开 http://127.0.0.1:7103。生产构建与预览：

```sh
pnpm --filter game-textworld build
pnpm --filter game-textworld preview
```

预览地址为 http://127.0.0.1:7203，也可以由游戏平台宿主加载。

## 第一阶段 MVP

- 默认使用贪心堆叠：枚举已有文字接触边的合法落点，选择包围范围最小、形状紧凑、靠近中心的方案。同时搜索四种朝向，综合包围面积、形状、中心距离、接触边长度、局部横竖比例和连续同向次数评分，取消转向必须节省 5% 空间的限制。旧块保持不动，保留四种文字朝向和安全间距。
- 追加前探测三侧被已有文字围住的凹陷空白，优先尝试原字号；需要时最多缩小 20%，普通文字不低于 18px、强调文字不低于 24px。缩小后重新测量并检查安全间距，放不下则回到正常多目标搜索；填凹陷后不再放大。
- 输入一句话后按 Enter 或点击「追加」。中文输入法确认候选词不会误提交。
- 文字使用 12 种深色配色与字号层次。短句更突出，问号和感叹号增加 25% 字号并加粗；新文字可在可用空间内适度放大，重新测量并检查碰撞。
- CollisionEngine 使用矩形碰撞、16px safeGap 和 Shift Search；当前方向搜索失败时转向重试。全部搜索失败则保留已有世界并提示，不提交重叠块。
- 每句通过文本长度过滤、最近两次排除、Weighted Random 选择动画，再独立随机参数和时长。支持淡入、缩放、滑入、模糊、打字机、弹出、旋转和浮起。超过 30 字不选择弹出和旋转。
- 新文字立即入场，相机旋转使用独立速度（默认为平移速度的 5 倍），不延迟文字动画。
- Canvas 通过 requestAnimationFrame 推进世界时钟；暂停时冻结动画进度。核心不读取浏览器时钟。
- 相机在螺旋和图谱模式中平滑跟随最新 TextBlock，使其保持视口中心，周围有多块大字号文字时适度拉远镜头；新增内容恢复跟随并退出全景，所有入场动画结束后平滑切回全景；Auto Demo 连续播放时保持跟随，停止并完成动画后进入全景，支持拖动、缩放及手动旋转；「全景」可查看不旋转的完整布局。
- Auto Demo 每 900ms 添加一句，点击停止；暂停期间不添加，重开和切换布局会停止演示。
- Debug 绘制最终 Block Bounds、Block ID、Direction、Rotation、WorldBounds 和 Camera Center，关闭时不绘制调试信息。
- 重开清空 Blocks、WorldBounds、方向、旋转、动画历史、世界时钟及相机状态。
- Renderer 通过只读数据契约读取世界，动画渲染变换不改变最终布局位置和碰撞尺寸。

## 验证

```sh
pnpm --filter game-textworld test
pnpm --filter game-textworld typecheck
pnpm --filter game-textworld build
```

单元测试覆盖 RotationEngine、CollisionEngine、LayoutEngine、AnimationEngine，以及相机和只读 Renderer。包含 500 个文字块的无碰撞与安全间距检查、完整顺时针转向周期、搜索失败不提交、动画历史排除和长文本过滤。

测试使用 TypeScript 编译器和 Node.js 内置测试运行器。编译产物写入临时目录，完成后自动删除，不需要额外的测试服务或浏览器依赖。

## 已有可选扩展

保留图谱模式、情绪配色和 Web Speech API 语音输入。它们不影响默认 MVP 螺旋流程：

- 图谱按自然文字尺寸蛇形分行，行宽随累计内容面积扩展，长短句形成错落的边缘。追加时不重排已有块，快速输入也不会出现旧块交叉移动；相机跟随最新文字，点击「全景」可查看完整图谱。切换布局会清空世界。
- 情绪影响色板选择，同一情绪的文字也会轮换颜色，不固定指定入场动画。
- 支持语音的浏览器可手动开启麦克风；不支持时使用输入框。暂停或失活时停止麦克风。

根据后续紧密堆叠需求，已加入贪心接触边搜索策略；没有加入 WebGL、PixiJS、Quadtree 或复杂 Anchor Scoring。

## 移动端

手机默认使用铺满视口的画布，隐藏文本框。开始弹窗提供布局选择、语音权限说明和开始按钮；点击开始即启动语音，并在支持的浏览器中请求原生全屏。不支持全屏时仍保持视口全屏布局。

右上角操作面板默认收起，展开后提供布局、Auto Demo、Debug、重开、暂停/继续、全屏、相机缩放/旋转/全景/跟随、语音开关及示例句。面板支持滚动，画布支持单指拖动和双指缩放。收起面板后仍显示语音状态和错误；不支持语音时可直接追加示例句或开启 Auto Demo。桌面保留文本输入。
